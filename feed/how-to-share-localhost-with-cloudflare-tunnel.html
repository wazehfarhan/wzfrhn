How to Share Your Localhost with the Internet Using Cloudflare Tunnel (Mac, Windows, and Linux)

When building a website or web application locally, it usually runs on localhost, which means only your computer can access it. However, sometimes developers need to share their work with teammates, clients, or testers.

A reliable solution is Cloudflare Tunnel, a secure tool that allows you to expose your local server to the internet without opening ports or configuring your router.

This guide explains how to set up Cloudflare Tunnel on macOS, Windows, and Linux.

What is Cloudflare Tunnel?

Cloudflare Tunnel creates a secure connection between your local computer and Cloudflare's global network. Instead of exposing your public IP address, traffic goes through Cloudflare's infrastructure.

Key advantages:

  • No port forwarding required
  • Automatic HTTPS security
  • Works behind NAT and firewalls
  • Easy setup for developers
  • Temporary public URLs for testing

Step 1: Install Cloudflare Tunnel

Cloudflare Tunnel runs through a CLI tool called cloudflared.

Install on macOS

Using Homebrew:

brew install cloudflared

Verify installation:

cloudflared --version

Install on Windows

Download the cloudflared.exe file from Cloudflare's official site. Move it to a folder such as C:\cloudflared. Open Command Prompt or PowerShell and run: 

cloudflared --version

Install on Linux

On most Linux distributions you can install using apt: 

sudo apt update
sudo apt install cloudflared

Check installation:

cloudflared --version

Step 2: Authenticate with Cloudflare

After installation, connect the CLI with your Cloudflare account.

Run:

cloudflared tunnel login

Your browser will open and ask you to log in to Cloudflare. Once approved, authentication credentials will be stored on your computer.

Step 3: Start Your Local Web Server

Before creating a tunnel, your local application must be running.

Example using Python:

python -m http.server 8000

Now your site will be available locally at:

http://localhost:8000

You can also use other servers like Node.js development server, PHP built-in server, or static HTML servers.

Step 4: Create a Public Tunnel

Open another terminal window and run:

cloudflared tunnel --url http://localhost:8000

Cloudflare will generate a public URL such as: https://example-name.trycloudflare.com

Anyone with this link can now access your local website.

How the Connection Works

The traffic flow looks like this:

Internet User
      ↓
Cloudflare Global Network
      ↓
Secure Cloudflare Tunnel
      ↓
Your Localhost Server

This method is secure because your computer makes an outbound connection to Cloudflare instead of exposing inbound ports.

Common Use Cases

Developers commonly use Cloudflare Tunnel for:

  • Sharing projects with clients
  • Testing APIs and webhooks
  • Demonstrating unfinished projects
  • Remote debugging
  • Temporary public hosting

Important Notes

  • The public URL works only while the tunnel is running.
  • Closing the terminal will stop the tunnel.
  • For long-term hosting, you can connect the tunnel to a custom domain.

Conclusion

Using Cloudflare Tunnel is one of the easiest ways to share a localhost server with the internet. It works on macOS, Windows, and Linux, making it a powerful tool for developers who need to quickly share their local projects.

With just a few commands, you can securely expose your development environment and collaborate more efficiently.
